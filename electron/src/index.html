À propos

Métré BA Agent v1.0

Pipeline Python qui lit un plan de fondations béton armé (PDF ou image) et produit un métré Excel structuré, un rapport PDF avec insights, un rapport LaTeX avec calculs détaillés, et un Excel d'optimisation.

Politique zéro-hallucination

Rien n'est estimé en silence. Chaque donnée vient du texte natif du PDF, de la géométrie vectorielle ou d'une lecture vision sourcée. Tout le reste est signalé dans le rapport.

Technologies

  • Extraction : pdfplumber, PyMuPDF, GLM-OCR, API Claude
  • Calcul : BAEL 91, Eurocode 2 (modules intégrés)
  • Excel : openpyxl (formules vivantes)
  • Rapports : reportlab (PDF), LaTeX (calculs détaillés)
  • UI : Electron + FastAPI
